## 📌 Project Overview

**Infosys AI Knowledge Assistant** is an enterprise-focused Generative AI application designed to help users search, understand, and interact with organizational knowledge using natural language.

The application combines **Retrieval-Augmented Generation (RAG)**, semantic vector search, LangChain workflows, Large Language Models, secure authentication, and a modern full-stack architecture.

Users can upload enterprise documents and ask questions such as:

```text
What is the company's leave policy?

Summarize the onboarding guidelines.

What does the uploaded project report say about revenue?

Find the relevant procedure for this issue.
