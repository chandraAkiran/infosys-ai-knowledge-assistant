## Recommended Demo Flow

1. Open the deployed frontend.
2. Log in as the employee user.
3. Open the Chat page.
4. Ask a question supported by an indexed document.
5. Review the grounded answer and retrieved sources.
6. Submit feedback on the answer.
7. Log out and sign in as the admin user.
8. Open the Upload page.
9. Upload a supported PDF or document.
10. Index the uploaded document.
11. Return to Chat and ask a question about the newly indexed document.
12. Open Analytics to review query and feedback information.
13. Open Admin to review users, connectors, governance, and audit information.

## MCP Demonstration

Use an incident ID such as `INC-1001` to demonstrate operational tool routing.

The system routes supported incident-status requests through the MCP connector and incorporates the returned operational information into the grounded response.
